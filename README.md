# 市立大溪國民中學・段考成績查詢與學習診斷系統

本專案為桃園市立大溪國民中學專用之「段考成績查詢與學習診斷系統」前端獨立發布庫。
採**前後端分離**架構運作，前端託管於 GitHub Pages，後端安全串接 Google Apps Script (GAS Version 19) 與 Google 試算表資料庫，**全站無任何第三方警告標籤或橫幅**，提供全校親師生最高規格之資安保護與流暢查詢體驗。

---

## 📌 系統功能特色

1. **學生與家長個人成績查詢**：
   - 即時查詢各次段考各學科原始分數、教育部五大領域動態折算總分與平均。
   - 動態雷達圖、PR 值、全校校排名（普通班與體育班雙軌分流評比機制）。
   - 班級五標對照（頂標、前標、均標、後標、底標）。
   - 學習中心學生免受試科目不以零分計，適性計算實際受試領域。

2. **班級導師專屬儀表板**：
   - 班級各科及格率、成績總覽與名次排序。
   - **各科分數區間分析**（11 分段統計，0 分與未評量嚴格分流隔離）。
   - **一鍵匯出 / 列印全班 A4 個人成績單**（一人一張，最佳化 CSS 列印排版與自動分頁）。

3. **教務處註冊組長全校管理專區**：
   - 跨全校 30 個班級（七、八、九年級）成績即時切換瀏覽與統計。
   - 全校導師通訊與指派管理。
   - 全校各班成績單批次列印功能。

4. **後端資安與權限防護 (Version 19)**：
   - 全面啟用 Token 鑑權機制（學生僅能查本人、導師僅能查本班、管理者可查全校）。
   - 導師首次登入強制變更密碼，且強制檢驗舊密碼。
   - 徹底封閉後端資料庫清空與危險維護端點。

## 🚀 GitHub Pages 新建與部署指引

本儲存庫為全新獨立建立，**完全不影響您在 GitHub 上既有的任何其他專案（如 `dsjh-stu`）**。

### 步驟一：在 GitHub 新建 Repository
1. 登入 GitHub，點擊右上角 **`+`** ➡️ **`New repository`**。
2. **Repository name** 輸入：`dsjh-score`（或您喜好的名稱）。
3. 設為 **`Public`**。
4. 點擊 **`Create repository`**。

### 步驟二：上傳本目錄檔案
1. 進入新建的 `dsjh-score` 儲存庫頁面。
2. 點擊 **`Add file`** ➡️ **`Upload files`**。
3. 將本目錄中的兩個檔案直接拖曳上傳：
   - `index.html`（系統主程式單檔版，132 KB）
   - `README.md`（本說明文件）
4. 點擊最下方綠色按鈕 **`Commit changes`**。

### 步驟三：啟動 GitHub Pages 網站
1. 點擊儲存庫上方的 **`Settings`** 標籤。
2. 左側功能選單點選 **`Pages`**。
3. 在 **Build and deployment** 下方的 **Branch**：
   - 選擇 **`main`** 分支，資料夾選擇 **`/(root)`**。
   - 點擊 **`Save`**。
4. 約等待 30 秒至 1 分鐘，GitHub Pages 即會產生專屬網址：
   👉 **`https://coolokey.github.io/dsjh-score/`**

開啟後即可直接使用，頂部無任何 Google 官方橫幅，資料直接與 Google 試算表即時連線！
