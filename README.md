# 市立大溪國民中學・段考成績查詢與學習診斷系統

本專案為桃園市立大溪國民中學專用之「段考成績查詢與學習診斷系統」前端獨立發布庫。
採**前後端分離**架構運作，前端託管於 GitHub Pages，後端安全串接 Google Apps Script (GAS Version 23) 與 Google 試算表資料庫，**全站無任何第三方警告標籤或橫幅**，提供全校親師生最高規格之資安保護與流暢查詢體驗。

---

## 📌 系統功能特色（Version 23 最新規範）

1. **各領域成績與平均精確規範**：
   - **社會平均**：七、八、九年級均完整計算並顯示（採地理、歷史、公民三科平均）。
   - **自然平均**：**僅九年級有**（依課綱折算：理化×3＋地科×2＋生物×1 ÷ 6），**七、八年級依課綱獨立採計生物或理化，不顯示自然平均**。
   - **未受試學生處理**：學習中心（學中）學生個別免測科目不以 0 分計算，動態依實際受試項目折算平均。

2. **六大統計指標嚴謹實作（班/年 平均、高標、低標）**：
   - 完整還原教務處 Excel 成績來源公式（`QUARTILE` 中位數 Q2 前後 50% 學生之平均值）。
   - **普通班與體育班母體完全分流**：
     - **普通班**：年平均、年高標、年低標以「**全校普通班（不含體育班）**」為母體計算。
     - **體育班**：年平均、年高標、年低標以「**全校全體學生（含體育班）**」為母體計算。
   - **班級導師專區**：全班定期評量成績名冊最下方完整呈現 6 行統計對照列（班平均、年平均、班高標、年高標、班低標、年低標）。
   - **學生個人專區**：各領域學科學習評量成績表直接並列 6 大指標對照，並明確標記年標參照母體。

3. **班級導師專屬儀表板**：
   - 班級各科及格率、成績總覽與名次排序。
   - **各科分數區間分析**（11 分段統計，0 分與未評量嚴格分流隔離）。
   - **一鍵匯出 / 列印全班 A4 個人成績單**（一人一張，最佳化 CSS 列印排版與自動分頁）。

4. **教務處註冊組長全校管理專區**：
   - 跨全校 30 個班級（七、八、九年級）成績即時切換瀏覽與統計。
   - 全校導師通訊與指派管理。
   - 全校各班成績單批次列印功能。

5. **後端資安與權限防護 (Version 23)**：
   - 全面啟用 Token 鑑權機制（學生僅能查本人、導師僅能查本班、管理者可查全校）。
   - 導師首次登入強制變更密碼，且強制檢驗舊密碼。
   - 徹底封閉後端資料庫清空與危險維護端點。

## 🔑 身分角色登入說明

| 角色身分 | 帳號格式 | 預設密碼規則 | 權限範圍 |
| :--- | :--- | :--- | :--- |
| **學生與家長** | 學生 7 碼學號（如：`1150001`） | 身分證末 4 碼 ＋ 生日 4 碼（共 8 碼） | 僅能查詢本人歷次段考成績與六大指標對照 |
| **班級導師** | 教師帳號（如：`tf51056`） | 預設密碼（首次登入強制變更新密碼） | 查詢所屬班級全體成績、名冊六大指標、各科區間分析、列印成績單 |
| **註冊組長** | 管理者帳號（`admin`） | 管理者專屬密碼 | 瀏覽全校 30 個班級成績與管理總覽 |
